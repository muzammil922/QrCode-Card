# Patient mobile (Expo) — M4 foundation

Synthetic patient app: register/login (demo OTP `123456`), digital QR card, synced prescription history from Flowlab API.

```powershell
cd "D:\My Team Projects\QrCode-Card\apps\mobile"
npm install
npx expo start
```

Optional: `EXPO_PUBLIC_API_BASE=https://codebase.flowlab.fun` (default).

Use Expo Go on a phone, or web/android emulator. Not an App Store release build yet.
